# Moonweave

Moonweave 是一个面向 4K 下落式音游的 Electron 谱面编辑器 MVP。

## 启动

```bash
npm install
npm run dev
```

首次启动时 Electron 可能需要下载对应平台的运行时。生产构建检查使用：

```bash
npm run build
```

打包为 Windows 安装程序：

```bash
npm run package:win
```

完成后，安装程序会生成在 `release-win/` 目录。

## 基本操作

- 在左侧选择 Note、Hold 或删除工具；Note 单击放置，Hold 依次点击起点和终点。
- 吸附支持 1/2、1/3、1/4、1/6、1/8、1/12、1/16、1/24、1/32。切换吸附不会修改已有音符的绝对时间。
- 鼠标滚轮滚动编辑时间轴；`Ctrl + 滚轮` 在 90～1320 px/s 范围缩放拍线间距，默认 230 px/s。
- `Q` 播放或暂停，暂停时吸附到最近的当前分拍线；`↑` / `↓` 按当前细分前进或后退一格，`Space` 前进一个主拍。
- 播放期间仍可放置音符，暂停会回正到最近的当前细分线。
- `Ctrl+Z` 撤回，`Ctrl+Shift+Z` 重做，`Ctrl+S` 保存。
- 点击已有音符进入多选状态，继续点击可累加选择；拖动任意选中音符会整体按当前分拍移动，横向移动会逐音符限制在四条轨道内。点击空白取消多选，点击删除批量移除选中音符。
- 区域操作：点击“选择区域”，依次点击起点与终点节拍线（可滚动到较远的位置）；完整落在区域内的 Note 和 Hold 会被选中。点击“复制”后选择“粘贴”，再点击目标节拍线，音符会按起点到目标的时间差整体复制。`Ctrl+C` 复制当前区域，`Ctrl+V` 粘贴到当前时间最近的分拍线。粘贴超出谱面时长时会提示并取消。
- 点击“镜像”会让区域内的音符按四条轨道左右翻转（1 ↔ 4、2 ↔ 3），保持时间与 Hold 长度。粘贴与镜像都可以撤回/重做。
- 点击“谱面试玩”进入试玩；使用 D、F、J、K（可修改）击打，`Space` 暂停或继续，`Esc` 返回编辑器。
- 试玩顶部的重玩按钮会立即清空本局判定并从头开始。
- Hold 需要在头部按下并保持到尾端。判定分为 Perfect、Good、Miss。

## 试玩计分规则

试玩左上角显示分数和实时准确率。整首谱面全部判定为 Perfect 时得 **10,000,000 分**。各音符不是固定分值，而是按谱面所有可判定 tick 平均分配满分；无音符的空谱面得 0 分。

- Note 有 1 个 tick。Hold 的头部有 1 个 tick，持续部分从头部之后每半拍（`30,000 ÷ BPM` 毫秒）检查一次；紧贴可视尾端之前的最后一段不设独立尾部/松手判定。实际持续 tick 只计满足 `tick 时间 + 半拍间隔 < Hold 尾端时间 - 0.01 毫秒` 的时刻。
- 每个 tick 的 Perfect 获得该 tick 的 100% 分值，Good 获得 50%，Miss 获得 0%。Hold 头部按下和持续 tick 分别判定；持续 tick 正在按住且未断 Hold 时为 Perfect，否则为 Miss。松手期间的持续 tick 会变成 Miss；重新按住可恢复后续 tick，但不会额外产生计分 tick。
- 设全谱面 tick 总数为 `N`、Perfect 数为 `P`、Good 数为 `G`，显示分数为 `round(10,000,000 × (P + 0.5 × G) ÷ N)`，每次判定后从累计值重新计算并四舍五入到整数，因此全 Perfect 恰好为 10,000,000 分。Miss 的那份分值和 Good 未获得的半份分值都会从满分中扣除。
- 实时准确率只统计**已经判定**的 tick：`(P + 0.5 × G) ÷ (P + G + Miss) × 100%`，显示两位小数；尚无判定时显示 100.00%。连击按非 Miss tick 累加，Miss 清零。
- 从当前进度开始试玩时，起点之前的整个 Note 或 Hold 的全部 tick 视为 Miss 并纳入准确率分母和整曲分数；重玩会清空本局结果并从头计分。

## 谱面文件

谱面以 `.moon.json` 保存，Note/Hold 均使用绝对毫秒时间。音频不会被导出到谱面文件中：文件只保存原音频的本地绝对路径（`audioPath`）和文件名（`audioName`）作为索引。因此在同一台机器再次导入时，会自动关联并直接使用原音频；如果音频被移动、改名或删除，编辑器会保留谱面并提示重新选择该音频。覆盖已有谱面前，旧文件会自动复制到同目录的 `.moonweave-backups` 文件夹。

当前 MVP 使用单 BPM + 全局 offset。变速 BPM、拍号事件、波形缓存和正式发行打包适合作为下一阶段功能。

谱面偏移使用毫秒值。修改 offset 会把拍线、Note 和 Hold 整体平移，并直接应用到试玩判定时间。BPM 的有效阈值为 20–400；输入框不会自动钳制，无效草稿在失焦时提示并回退到最近一次有效值。

界面控件统一通过 `src/components/ui.tsx` 中的 shadcn 组件层使用，配置入口为 `components.json`。
