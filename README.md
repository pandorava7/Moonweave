# Moonweave

Moonweave 是一个面向 4K 下落式音游的 Electron 谱面编辑器 MVP。

## 启动

```bash
npm install
npm run dev
```

首次启动时 Electron 可能需要下载对应平台的运行时。生产构建检查使用：

```bash
npm run build
```

## 基本操作

- 在左侧选择 Note、Hold 或删除工具；Note 单击放置，Hold 依次点击起点和终点。
- 吸附支持 1/2、1/3、1/4、1/6、1/8、1/12、1/16、1/24、1/32。切换吸附不会修改已有音符的绝对时间。
- 鼠标滚轮滚动编辑时间轴；`Ctrl + 滚轮` 在 90～1320 px/s 范围缩放拍线间距，默认 230 px/s。
- `Q` 播放或暂停，暂停时吸附到最近的当前分拍线；`↑` / `↓` 按当前细分前进或后退一格，`Space` 前进一个主拍。
- 播放期间仍可放置音符，暂停会回正到最近的当前细分线。
- `Ctrl+Z` 撤回，`Ctrl+Shift+Z` 重做，`Ctrl+S` 保存。
- 点击已有音符进入多选状态，继续点击可累加选择；拖动任意选中音符会整体按当前分拍移动，横向移动会逐音符限制在四条轨道内。点击空白取消多选，点击删除批量移除选中音符。
- 点击“谱面试玩”进入试玩；使用 F、G、H、J（可修改）击打，`Space` 暂停或继续，`Esc` 返回编辑器。
- 试玩顶部的重玩按钮会立即清空本局判定并从头开始。
- Hold 需要在头部按下并保持到尾端。判定分为 Perfect、Good、Miss。

## 谱面文件

谱面以 `.moon.json` 保存，Note/Hold 均使用绝对毫秒时间。覆盖已有谱面前，旧文件会自动复制到同目录的 `.moonweave-backups` 文件夹。

当前 MVP 使用单 BPM + 全局 offset。变速 BPM、拍号事件、波形缓存和正式发行打包适合作为下一阶段功能。

谱面偏移使用毫秒值。修改 offset 会把拍线、Note 和 Hold 整体平移，并直接应用到试玩判定时间。BPM 的有效阈值为 20–400；输入框不会自动钳制，无效草稿在失焦时提示并回退到最近一次有效值。

界面控件统一通过 `src/components/ui.tsx` 中的 shadcn 组件层使用，配置入口为 `components.json`。
